# 合规声明

采文解码台是面向本地文件的编码证据与转码审计工具。使用本项目即表示使用者确认：仅处理本人拥有、已获得授权或依法可以处理的本地响应文件。

## 允许的使用范围

- 对自有采集管道已经落盘的 HTML、XML、TXT、CSS 响应做编码诊断。
- 在隔离环境中核对编码声明与实际字节的冲突。
- 为归档、迁移或质量复核生成 UTF-8 副本和证据清单。
- 在教学、竞赛、内部评测或研究环境中使用仓库内置的离线 fixture。

## 明确禁止的使用范围

- 未授权抓取、批量探测、绕过访问控制、规避风控或规避检测。
- 处理真实账号、真实令牌、真实密钥、真实凭据或个人敏感信息。
- 将本项目改造成网络爬虫、代理池、浏览器自动化、漏洞扫描或目标探测系统。
- 未经批准上传本地响应、SQLite 台账或诊断结果到外部服务。
- 利用项目输出实施对第三方系统的攻击、骚扰或数据侵害。

## 离线承诺

运行期不发起任何网络请求：

- 不导入 HTTP 客户端库来访问远程资源；
- 不下载规则、字体、CSS、JavaScript、图片或模型；
- 不读取云端配置，不调用外部 API；
- 报告 HTML 不包含 CDN、远程链接、远程脚本或跟踪像素；
- Flask 复核台只允许回环地址，默认 `127.0.0.1:5017`，没有上传或修改接口。

测试完全使用仓库内 fixture、`tmp_path` 与 Flask `test_client`，不会连接真实站点。

## 数据与密钥

仓库不包含真实密钥、令牌、账号、公司名、真实域名、真实 IP 目标或个人信息。样本中的外部地址只使用保留域名 `example.invalid`。配置和代码中也不应写入真实凭据；如果使用者自行修改配置，应自行承担授权与隐私合规责任。

## 源文件保护

扫描根目录被视为只读证据源：

- 程序只读取源文件与 sidecar；
- 转码输出、manifest、HTML 报告和 SQLite 台账写入独立输出目录；
- 配置校验拒绝将输出目录放在扫描根目录内；
- 不修改原始 fixture 与其响应头 sidecar。

## 诊断而非自动修复

乱码诊断只输出风险等级、错误码、行号/偏移和证据片段，不自动做二次转码。典型 mojibake 可能在特定上下文中是合法字符组合，是否修复应由人工结合响应头、采集日志和原始字节复核决定。

## 报告责任

使用者在对外共享报告前，应检查报告中是否包含业务路径、主机名或其他敏感元数据。本项目不会替使用者做数据脱敏或访问控制决策。
